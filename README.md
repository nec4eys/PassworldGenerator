# PassworldGenerator
Пользователь может выбрать длину сгенерированного пароля от 1 до 99.
Пользователь может выбрать один или несколько из следующих вариантов: Uppercase Letters, Lowercase Letters, Numbers, Symbols для добавления соответствующих символов в пароль.
Нажав кнопку Generate, пользователь увидит сгенерированный пароль.
Пользователь может нажать кнопку Copy, чтобы сохранить пароль в буфер обмена.
